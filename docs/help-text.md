# How to Play

The core rules and the How to Play screen.

## Core rules [rules]
Rule 1: Tic-tac-toe, where every square is its own mini-game. Win it to claim the square.
Rule 2: On your turn, make one move in any square.
Rule 3: Three squares in a row wins the match. No line left for anyone? A draw.

# Modes

The explainers for Super Chaos and Classic.

## Super Chaos [superchaos]
Play: Both players move at the same time. Each round, pick any square and make one move. When you're both done (or time runs out), you'll see what your opponent did. If both players win the same square in the same round, it resets. Run out of time and you miss the round; miss two in a row and you lose.
Win: Three in a row wins.

## Mode selector [mode]
Super Chaos: X and O move at the same time.
Classic: X goes first, then you take turns.

## Timer (the host's "?") [timer]
Text: Your time for the whole game. +5s a move. Run out and you lose.
