# How to Play

The core rules and the How to Play screen.

## Core rules [rules]
Rule 1: Tic-tac-toe, where every square is its own mini-game. Win the mini-game to claim the square. Get three squares in a row to win.
Rule 2: On your turn, make one move in any square. Every game keeps going until someone wins it.
Rule 3: Once neither player can get three in a row any more, the match ends in a draw.

# Modes

The explainers for Super Chaos and Classic.

## Super Chaos [superchaos]
Play: Both players move at the same time. Each round, pick any square and make one move. When you're both done (or time runs out), you'll see what your opponent did. Win the same square in the same round and it resets. Run out of time and you miss the round; miss two in a row and you lose.
Win: Three in a row wins.

## Mode selector [mode]
Super Chaos: X and O move at the same time.
Classic: X goes first, then you take turns.
